Ручка WS /v1/realtime — протокол OpenAI Realtime API в режиме транскрипции: сюда можно направить готовый клиент OpenAI, указав наш base_url. Аудио уходит как input_audio_buffer.append (base64, PCM 24 кГц), сервер сам режет поток на фразы своим VAD. Текст приходит …transcription.delta — только уже стабилизированными словами, потому что дельту в этом протоколе нельзя отозвать, — и …transcription.completed с полным текстом фразы. Без галочек-расширений поведение ровно стандартное. С «нестабильным хвостом» видно и то, что ещё может измениться (серым); если сервер переписал уже зафиксированное (числа, имена), фраза перерисовывается и изменение подсвечивается. Под результатом — сырой поток JSON-событий сервера.
Ручка POST /stt/emotion — отдельная модель GigaAMEmo, отдельный запрос. В OpenAI-контракте эмоций нет вовсе, поэтому это наше расширение. Возвращает вероятности четырёх классов: злость, грусть, нейтрально, позитив.
